## 缘起

大多数博客主题长得越来越像：大圆角、玻璃拟态、渐变色按钮。我想做一个完全相反的方向——**像一页手写稿纸**。

点阵稿纸底、墨色硬边框、单方向硬阴影、随手贴的彩色贴纸。这就是 MangaPaper。

## 技术选型

整套模板只有一条原则：**纯静态、零后端**。

| 能力 | 方案 |
| --- | --- |
| 框架 | Astro 纯静态构建 |
| 字体 | Maple Mono NF CN，CDN 分包按需加载 |
| 搜索 | Pagefind 静态索引 |
| 私密文章 | 构建时 AES-256-GCM 加密 |

## 使用方式

克隆模板仓库，替换示例文章，配置环境变量，部署到你喜欢的静态托管平台即可。

```bash
npm install
npm run dev
```
